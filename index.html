Siapa namamu?

Nama dipakai untuk papan skor.

Cara main

  1. Kamu mulai dari sebuah vektor. Ubah menjadi vektor target (garis putus-putus merah muda).
  2. Tiap tombol adalah operasi vektor. Satu klik = satu langkah, dan jumlah langkah terbatas.
  3. Sampai di target dalam batas langkah = level selesai. Makin sedikit langkah, makin banyak bintang.
  4. Pintasan: tombol 1–9 untuk operasi, Z urungkan, R ulang.
